# Sitio a analizar: Landing Page

Organización de archivos:

```md
/css/style.css
/img/... # en caso de existir imágenes
/js/..
/index.html 
```

## Resúmen

#### Semántica HTML5:

Usar etiquetas como:
```html
<nav>
<main>
<article>
<aside>
```
Para mejorar la estructura semántixa y accesiblidad.


#### Accesibilidad:
Usar la etiqueta `<label>` para formularios. Use `alt` en imágenes en caso de existir.


#### SEO Básico:

Agregue metaeqiquetas como `description`, `keywords`, etc.

Agrega metaetiquetas como description, keywords, etc.

Usa títulos <h1> solo una vez por página y de forma jerárquica (h2, h3...).

Responsive Design:

Asegúrate de que el diseño se vea bien en móviles (usa viewport, media queries en CSS, flexbox o grid).

Seguridad:

Si usas target="_blank", siempre añade rel="noopener noreferrer" para evitar ataques de tipo reverse tabnabbing.
