#### Semántica HTML5:

Usar etiquetas como:
```html
<nav>
<main>
<article>
<aside>
```
Para mejorar la estructura semántixa y accesiblidad.


#### Accesibilidad:
Usar la etiqueta `<label>` para formularios. Use `alt` en imágenes en caso de existir.
